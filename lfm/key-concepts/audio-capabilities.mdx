LFM3-Audio is a single end-to-end speech model: it listens to audio, reads text, and answers in text, speech, or interleaved text and speech. One model covers speech recognition, text-to-speech, speech translation, spoken chat, and tool calling from spoken requests.

The examples below use [LFM3-Audio-2B](/lfm/models/lfm3-audio-2b) with Transformers. For images and video as well as audio, see [Omni Capabilities](/lfm/key-concepts/omni-capabilities).

## Setup

Install Transformers and the packages used by the examples. `librosa` and `soundfile` load and save audio files, and `datasets` loads a sample recording. A GPU is recommended; the model runs in bfloat16.

```bash
pip install "transformers>=5.20.2" accelerate datasets librosa soundfile
```

Load the model and processor with `trust_remote_code=True`. The processor bundles the audio codec, which turns generated speech codes into a 24 kHz waveform. Access it as `processor.audio_tokenizer` and move it to the model's device and dtype.

```python
import torch
from transformers import AutoModelForMultimodalLM, AutoProcessor

model_id = "LiquidAI/LFM3-Audio-2B"
device = "cuda" if torch.cuda.is_available() else "cpu"
dtype = torch.bfloat16 if device == "cuda" else torch.float32

model = AutoModelForMultimodalLM.from_pretrained(
    model_id, dtype=dtype, device_map=device, trust_remote_code=True
).eval()
processor = AutoProcessor.from_pretrained(model_id, trust_remote_code=True)
codec = processor.audio_tokenizer.to(device=device, dtype=dtype).eval()
```

### Output modes

Every task is a chat conversation, and the system prompt describes the task. Text output is the default: generation starts in text mode and switches to speech or interleaved output when the model emits an output-mode token.

To select a mode from the start, prefill the assistant turn: put one of the prefixes below in a final assistant message and let the model continue it.

| Assistant prefill | Behavior |
|---|---|
| None | Start in text mode. The model can still emit a token that switches modes. |
| `<\|audio_start\|>` | Start speech-only output, for example text-to-speech, until an end-of-audio frame. |
| `<\|mixed_start\|>` | Start interleaved text and speech, alternating blocks of 6 text tokens and 12 speech frames. |
| `<think>` | Begin a thinking block. The answer follows the closing `</think>`. |
| `<think></think>` | Supply an empty thinking block, so the answer starts immediately. |

The thinking prefixes are for text-only answers. For those, also pass `suppress_mixed=True` and `suppress_audio_out=True` to `generate()`, so the model doesn't switch to speech.

### Helper

The helper below runs one assistant turn and returns the text and the speech waveform, if any. When you pass `prefill`, it sets `continue_final_message=True`, so generation continues the prefilled message instead of starting a new assistant turn. For speech and interleaved output, pass `SPEECH_SAMPLING`.

```python
import soundfile as sf

SAMPLE_RATE_OUT = 24_000  # the codec decodes to 24 kHz
SPEECH_SAMPLING = dict(audio_temperature=1.0, audio_top_k=128, audio_repetition_penalty=1.1, audio_repetition_window=4096)


@torch.inference_mode()
def generate(conversation, prefill=None, max_new_tokens=512, **generate_kwargs):
    """Runs one assistant turn. Returns (text, waveform or None)."""
    if prefill is not None:
        conversation = conversation + [{"role": "assistant", "content": prefill}]
    inputs = processor.apply_chat_template(
        conversation,
        add_generation_prompt=prefill is None,
        continue_final_message=prefill is not None,
        tokenize=True,
        return_dict=True,
        return_tensors="pt",
    ).to(device)
    outputs = model.generate(**inputs, max_new_tokens=max_new_tokens, **generate_kwargs)
    text = processor.decode(outputs.sequences[0, inputs["input_ids"].shape[1]:], skip_special_tokens=True)
    waveform = None
    if outputs.audio_codes is not None and outputs.audio_lengths[0] > 0:
        codes = outputs.audio_codes[:1, :, : outputs.audio_lengths[0]]
        waveform = codec.decode(codes).audio_values[0].float().cpu().numpy().squeeze()
    return text, waveform
```

## Speech recognition

Use the system prompt `Perform ASR in <language>.` with the English name of the language, or `Perform ASR.` to let the model detect it.

Pass audio in the user turn as `{"type": "audio", "audio": ...}`, where the value is a file path or URL. The processor resamples it to 16 kHz mono. This example transcribes a LibriSpeech clip:

```python
import io
from datasets import Audio as AudioFeature, load_dataset

librispeech = load_dataset("hf-internal-testing/librispeech_asr_dummy", "clean", split="validation")
librispeech = librispeech.cast_column("audio", AudioFeature(decode=False))

sample = librispeech[0]
speech, sr = sf.read(io.BytesIO(sample["audio"]["bytes"]))
sf.write("librispeech.wav", speech, sr)
print("Reference:", sample["text"])

transcript, _ = generate([
    {"role": "system", "content": "Perform ASR in English."},
    {"role": "user", "content": [{"type": "audio", "audio": "librispeech.wav"}]},
])
print("Transcript:", transcript)
```

**Output**

```text
Reference: MISTER QUILTER IS THE APOSTLE OF THE MIDDLE CLASSES AND WE ARE GLAD TO WELCOME HIS GOSPEL
Transcript: Mr. Quilter is the apostle of the middle classes, and we are glad to welcome his gospel.
```

## Text-to-speech

Use the system prompt `Perform TTS in <language> using a <female|male> voice.` and prefill `<|audio_start|>`.

Supported languages and accents: Arabic, Danish, German, Greek, British English, American English, Finnish, French, Hebrew, Italian, Japanese, Korean, Dutch, Polish, Portuguese, Spanish, Swedish, Turkish, and Chinese.

```python
torch.manual_seed(0)
_, tts_en = generate(
    [
        {"role": "system", "content": "Perform TTS in American English using a female voice."},
        {"role": "user", "content": "I made a little plan for today: go for a walk, find a new workout playlist, and try a new cake recipe"},
    ],
    prefill="<|audio_start|>",
    **SPEECH_SAMPLING,
)
sf.write("tts_en.wav", tts_en, SAMPLE_RATE_OUT)

_, tts_fr = generate(
    [
        {"role": "system", "content": "Perform TTS in French using a male voice."},
        {"role": "user", "content": "On pourrait inventer une nouvelle recette ce soir. Si le résultat est étrange, on lui donnera un nom très chic."},
    ],
    prefill="<|audio_start|>",
    **SPEECH_SAMPLING,
)
sf.write("tts_fr.wav", tts_fr, SAMPLE_RATE_OUT)
```

As a quick check, let the model transcribe its own French speech:

```python
transcript, _ = generate([
    {"role": "system", "content": "Perform ASR in French."},
    {"role": "user", "content": [{"type": "audio", "audio": "tts_fr.wav"}]},
])
print("Transcript:", transcript)
```

**Output**

```text
Transcript: On pourrait inventer une nouvelle recette ce soir. Si le résultat est étrange, on lui donnera un nom très chic.
```

## Speech translation

Translation works best into or out of English. The system prompt picks the direction and the output modality:

| Direction | System prompt |
|---|---|
| Speech → text | `Convert the speech in {source} to written {target}.` |
| Text → speech | `Convert this {source} text into {target} speech.` |
| Speech → speech | `Produce spoken {target} for the following {source} audio.` |

Speech to text, using the French clip from the text-to-speech example:

```python
translation, _ = generate([
    {"role": "system", "content": "Convert the speech in French to written English."},
    {"role": "user", "content": [{"type": "audio", "audio": "tts_fr.wav"}]},
])
print("Speech → text:", translation)
```

**Output**

```text
Speech → text: We could invent a new recipe tonight. If the result is strange, we will give it a very funny name.
```

Speech to speech, without a prefill: the model writes the translation and speaks it.

```python
text_de, spoken_de = generate(
    [
        {"role": "system", "content": "Produce spoken German for the following English audio."},
        {"role": "user", "content": [{"type": "audio", "audio": "tts_en.wav"}]},
    ],
    **SPEECH_SAMPLING,
)
print("Speech → speech (English → German):", text_de)
sf.write("german.wav", spoken_de, SAMPLE_RATE_OUT)
```

**Output** (text part; the speech is saved to `german.wav`)

```text
Speech → speech (English → German): Ich habe einen kleinen Plan für heute gemacht, nämlich einen Spaziergang, eine neue Workout-Playlist zu finden und ein neues Kuchenrezept auszuprobieren.
```

## Spoken chat

With the system prompt `Respond with interleaved text and audio.` and the `<|mixed_start|>` prefill, the model answers conversationally in text and speech at the same time, so speech can start playing before the full answer is written.

This example first records a spoken question with text-to-speech, then asks it:

```python
_, question = generate(
    [
        {"role": "system", "content": "Perform TTS in American English using a male voice."},
        {"role": "user", "content": "I want to move more, but I have not found an activity I enjoy. How can I try a few options and build a small habit?"},
    ],
    prefill="<|audio_start|>",
    **SPEECH_SAMPLING,
)
sf.write("question.wav", question, SAMPLE_RATE_OUT)

reply, reply_speech = generate(
    [
        {"role": "system", "content": "Respond with interleaved text and audio. Give two practical ideas in short, friendly sentences."},
        {"role": "user", "content": [{"type": "audio", "audio": "question.wav"}]},
    ],
    prefill="<|mixed_start|>",
    max_new_tokens=1024,
    **SPEECH_SAMPLING,
)
print("Text:", reply)
sf.write("reply.wav", reply_speech, SAMPLE_RATE_OUT)
```

**Output** (text part; the speech is saved to `reply.wav`)

```text
Text: Try a 15 minute walk in a new neighborhood each day and note how you feel, or sign up for a beginner class in something you've never tried before. Which of those sounds more doable for you?
```

For streaming applications, `model.generate()` accepts `streamer` for text tokens and `audio_streamer` for speech frames, and the codec decodes those frames incrementally, so speech can be played as it is generated.

## Speech-to-text chat

In this mode, the model behaves like a text LLM that also accepts speech. No system prompt is needed. Prefill `<think>` to let the model reason first; it closes the reasoning with `</think>`, and the answer follows. Pass `suppress_mixed=True` and `suppress_audio_out=True` to keep the answer in text.

```python
text, _ = generate(
    [{"role": "user", "content": [{"type": "audio", "audio": "question.wav"}]}],
    prefill="<think>",
    max_new_tokens=2048,
    suppress_mixed=True,
    suppress_audio_out=True,
)
thinking, _, answer = text.partition("</think>")
print("Thinking:", thinking.strip())
print("Answer:", answer.strip())
```

**Output** (truncated)

```text
Thinking: We need to answer the question: "I want to move more, but I have not found an activity I enjoy. How can I try a few options and build a small habit?"

1.  **Analyze the User's Request:**
    *   **Goal:** Move more.
    *   **Problem:** Hasn't found an activity they enjoy.
    *   **Solution Needed:** How to try a few options and build a small habit.
...
Answer: It is completely normal to struggle to find an activity you enjoy when you want to move more. The key to overcoming this is to **lower the barrier to entry** and focus on the *process* rather than the *outcome*.
...
```

To skip thinking, prefill an empty `<think></think>` block, so the answer starts immediately:

```python
answer, _ = generate(
    [{"role": "user", "content": [{"type": "audio", "audio": "question.wav"}]}],
    prefill="<think></think>",
    max_new_tokens=1024,
    suppress_mixed=True,
    suppress_audio_out=True,
)
print("Answer:", answer.strip())
```

## Audio understanding

Text and audio can be mixed in the same user turn, for example a recording plus a written question about it. Questions can address speech, music, background sounds, or events.

```python
answer, _ = generate(
    [{"role": "user", "content": [
        {"type": "audio", "audio": "librispeech.wav"},
        {"type": "text", "text": "Who or what is the speaker talking about, and what is their attitude towards it?"},
    ]}],
    prefill="<think></think>",
    max_new_tokens=512,
    suppress_mixed=True,
    suppress_audio_out=True,
)
print("Answer:", answer.strip())
```

**Output**

```text
Answer: The speaker is talking about **Mr. Quilter**, who is described as "the apostle of the middle classes." The speaker's attitude is one of welcome and approval—"we're glad to welcome his gospel," indicating a positive, supportive stance toward Mr. Quilter's message.
```

## Tool calling

This example turns one spoken request into two function calls: cancel a streaming-platform subscription at the end of the billing period, then subscribe to a podcast platform's Max plan with monthly billing. StreamBox and PodSpace are fictional services, and the example only prints the proposed calls.

List the tools in the system prompt, between `<tools>` and `</tools>`, one JSON object per line. The user asks by voice, and the model returns one `<tool_call>` block per call.

```python
import json

tools = [
    {
        "name": "cancel_subscription",
        "description": "Cancel the signed-in user's subscription to a streaming platform at the specified time.",
        "parameters": {
            "type": "object",
            "properties": {
                "platform": {"type": "string", "enum": ["StreamBox"]},
                "effective_when": {
                    "type": "string",
                    "enum": ["immediately", "end_of_billing_period"],
                },
            },
            "required": ["platform", "effective_when"],
        },
    },
    {
        "name": "subscribe_to_podcast_platform",
        "description": "Subscribe the signed-in user to a podcast platform with the chosen plan and billing frequency.",
        "parameters": {
            "type": "object",
            "properties": {
                "platform": {"type": "string", "enum": ["PodSpace"]},
                "plan": {"type": "string", "enum": ["basic", "plus", "max"]},
                "billing_frequency": {"type": "string", "enum": ["monthly", "annual"]},
            },
            "required": ["platform", "plan", "billing_frequency"],
        },
    },
]
tool_prompt = (
    "Return tool calls for both requested actions, in the order requested. "
    "Do not claim that an action has completed without a tool result.\n"
    "List of tools:\n<tools>\n" + "\n".join(json.dumps(t) for t in tools) + "\n</tools>"
)

# Record the spoken request
_, request = generate(
    [
        {"role": "system", "content": "Perform TTS in British English using a female voice.\n\n Current date: 27 October 2026"},
        {"role": "user", "content": "Please cancel my StreamBox subscription starting December first. Then subscribe me to PodSpace on the Max plan, billed monthly."},
    ],
    prefill="<|audio_start|>",
    **SPEECH_SAMPLING,
)
sf.write("request.wav", request, SAMPLE_RATE_OUT)

call, _ = generate(
    [
        {"role": "system", "content": tool_prompt},
        {"role": "user", "content": [{"type": "audio", "audio": "request.wav"}]},
    ],
    prefill="<think></think>",
    max_new_tokens=512,
    suppress_mixed=True,
    suppress_audio_out=True,
)
print(call)
```

**Output** (the model's reasoning is truncated)

```text
We need to call the cancel_subscription tool first to cancel the StreamBox subscription. ...
</think>
<tool_call>
<function=cancel_subscription>
<parameter=platform>
StreamBox
</parameter>
<parameter=effective_when>
end_of_billing_period
</parameter>
</function>
</tool_call>
<tool_call>
<function=subscribe_to_podcast_platform>
<parameter=platform>
PodSpace
</parameter>
<parameter=plan>
max
</parameter>
<parameter=billing_frequency>
monthly
</parameter>
</function>
</tool_call>
```

Generated calls use the LFM3 `<tool_call>` XML format. Your application parses and executes the calls and returns the results as `tool` messages. See [Tool Use](/lfm/key-concepts/tool-use) for the full workflow.

## FAQ

**Which model should I use?**

Use `LFM3-Audio-2B` for speech and audio tasks: transcription, speech synthesis, translation, spoken chat, audio understanding, and spoken tool calls. Use `LFM3-Omni-2B` when the request also involves images or video. See [Omni Capabilities](/lfm/key-concepts/omni-capabilities).

**What audio input is supported?**

Audio files are resampled to 16 kHz mono on load. Speech output is a 24 kHz waveform.

**Can the model stream speech?**

Yes. LFM3-Audio-2B uses a causal audio encoder that supports live audio input and incremental prefill, and its audio codec supports streaming encoding and decoding. In Transformers, pass `streamer` and `audio_streamer` to `model.generate()`.

**Does the model reason before answering?**

For text-only answers, prefill `<think>` to let the model reason first, or `<think></think>` to answer directly.
