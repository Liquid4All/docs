LFM3-Audio and LFM3-Omni models' audio capabilities enable the model to listen to and speak with users.
These models take text or audio as input and respond with text, speech, or both. They support common speech tasks such as transcription, speech synthesis, voice chat, and translation, and they can answer questions about the speech, sounds, and events in a recording. They also support tool calling from spoken requests. LFM3-Omni additionally takes images and video, so users can ask spoken questions about what the model sees.

The examples below show how to send audio to LFM3-Audio and LFM3-Omni models.

Install PyTorch, Transformers, and the packages used by the examples. `librosa` and `soundfile` load and save audio files, and `datasets` loads a sample recording. `torchvision`, `torchcodec`, and `Pillow` are used by the LFM3-Omni image and video examples, and `torchcodec` needs FFmpeg.

Load LFM3-Audio-2B and its processor with the checkpoint's custom code. The processor bundles the audio codec, which turns generated speech tokens into a 24 kHz waveform.

```python
import torch
import soundfile as sf

from transformers import AutoModelForMultimodalLM, AutoProcessor

MODEL_ID = "LiquidAI/LFM3-Audio-2B"
device = "cuda" if torch.cuda.is_available() else "cpu"
dtype = torch.bfloat16 if device == "cuda" else torch.float32

model = AutoModelForMultimodalLM.from_pretrained(
    MODEL_ID, dtype=dtype, device_map=device, trust_remote_code=True
).eval()
processor = AutoProcessor.from_pretrained(MODEL_ID, trust_remote_code=True)
codec = processor.audio_tokenizer.to(device=device, dtype=dtype).eval()
```

For speech output, use `audio_temperature=0.4` and `audio_repetition_penalty=1.2`. For text-only output, set `suppress_mixed=True` and `suppress_audio_out=True`.

Besides a LibriSpeech recording, the examples use three short recordings: `french.wav` says "Bonjour ! Le petit déjeuner est servi de sept heures à dix heures.", `question.wav` asks "I have a job interview tomorrow morning. Any tips to calm my nerves?", and `request.wav` asks "Do I need an umbrella in Edinburgh today?" You can record them with the text-to-speech example below, or replace them with your own audio files.

## Speech recognition

Use the system prompt `Perform ASR in <language>.`, where `<language>` is the English name of the language. To let the model infer the language, use `Perform ASR.` This example transcribes a LibriSpeech recording.

```python
import io
from datasets import Audio, load_dataset

librispeech = load_dataset("hf-internal-testing/librispeech_asr_dummy", "clean", split="validation")
librispeech = librispeech.cast_column("audio", Audio(decode=False))
sample = librispeech[0]
speech, sr = sf.read(io.BytesIO(sample["audio"]["bytes"]))
sf.write("librispeech.wav", speech, sr)
print("Reference:", sample["text"])

conversation = [
    {"role": "system", "content": "Perform ASR in English."},
    {"role": "user", "content": [{"type": "audio", "audio": "librispeech.wav"}]},
]

inputs = processor.apply_chat_template(
    conversation,
    add_generation_prompt=True,
    tokenize=True,
    return_dict=True,
    return_tensors="pt",
).to(device)

with torch.no_grad():
    outputs = model.generate(
        **inputs,
        max_new_tokens=1024,
        suppress_mixed=True,
        suppress_audio_out=True,
        return_dict_in_generate=True,
    )

text = processor.decode(
    outputs.sequences[0, inputs["input_ids"].shape[1]:],
    skip_special_tokens=True,
)
print(text)
```

**Output**

```text
Reference: MISTER QUILTER IS THE APOSTLE OF THE MIDDLE CLASSES AND WE ARE GLAD TO WELCOME HIS GOSPEL
Mr. Quilter is the apostle of the middle classes, and we are glad to welcome his gospel.
```

## Text-to-speech

Use the system prompt `Perform TTS in <language> using a <gender> voice.`, with a `female` or `male` voice. Prefill the assistant turn with `<|audio_start|>`.

The supported speech languages and locales are Arabic, Danish, German, Greek, British English, American English, Finnish, French, Hebrew, Italian, Japanese, Korean, Dutch, Polish, Portuguese, Spanish, Swedish, Turkish, and Chinese.

```python
conversation = [
    {"role": "system", "content": "Perform TTS in American English using a female voice."},
    {"role": "user", "content": "Liquid AI builds efficient foundation models that run on any device."},
    {"role": "assistant", "content": "<|audio_start|>"},
]

inputs = processor.apply_chat_template(
    conversation,
    continue_final_message=True,
    tokenize=True,
    return_dict=True,
    return_tensors="pt",
).to(device)

with torch.no_grad():
    outputs = model.generate(
        **inputs,
        max_new_tokens=256,
        audio_temperature=0.4,
        audio_repetition_penalty=1.2,
        return_dict_in_generate=True,
    )
    waveform = codec.decode(
        outputs.audio_codes[:1, :, :outputs.audio_lengths[0]]
    ).audio_values[0]  # 24 kHz

sf.write("tts_en.wav", waveform.float().cpu().numpy().squeeze(), 24_000)
```

## Voice chat

Use the system prompt `Respond with interleaved text and audio.` and prefill the assistant turn with `<|mixed_start|>`. The user input can be text or audio, and the model responds in a conversational style with interleaved text and speech.

```python
conversation = [
    {"role": "system", "content": "Respond with interleaved text and audio."},
    {"role": "user", "content": [{"type": "audio", "audio": "question.wav"}]},
    {"role": "assistant", "content": "<|mixed_start|>"},
]

inputs = processor.apply_chat_template(
    conversation,
    continue_final_message=True,
    tokenize=True,
    return_dict=True,
    return_tensors="pt",
).to(device)

with torch.no_grad():
    outputs = model.generate(
        **inputs,
        max_new_tokens=1024,
        audio_temperature=0.4,
        audio_repetition_penalty=1.2,
        return_dict_in_generate=True,
    )
    text = processor.decode(
        outputs.sequences[0, inputs["input_ids"].shape[1]:],
        skip_special_tokens=True,
    )
    waveform = codec.decode(
        outputs.audio_codes[:1, :, :outputs.audio_lengths[0]]
    ).audio_values[0]  # 24 kHz

print(text)
sf.write("reply.wav", waveform.float().cpu().numpy().squeeze(), 24_000)
```

**Output** (text part; the speech is saved to `reply.wav`)

```text
A quick breath reset before you walk in can calm you fast, just inhale for four counts, hold two, exhale four. Picture yourself succeeding and notice the details of the room, like the lighting and the chair. A short walk around the block can also clear your head. Would you like a simple breathing script to try right now?
```

This example saves the complete response. For streaming applications, `model.generate()` accepts `streamer` for text tokens and `audio_streamer` for speech frames, and the codec decodes those frames incrementally, so speech can be played as it is generated.

## Spoken questions with text answers

For a text-only answer, no specific system prompt is needed. Prefill `<think>` to let the model reason before answering, or `<think></think>` for a direct response.

```python
use_thinking = True
conversation = [
    {"role": "user", "content": [{"type": "audio", "audio": "question.wav"}]},
    {"role": "assistant", "content": "<think>" if use_thinking else "<think></think>"},
]

inputs = processor.apply_chat_template(
    conversation,
    continue_final_message=True,
    tokenize=True,
    return_dict=True,
    return_tensors="pt",
).to(device)

with torch.no_grad():
    outputs = model.generate(
        **inputs,
        max_new_tokens=2048,
        suppress_mixed=True,
        suppress_audio_out=True,
        return_dict_in_generate=True,
    )
    text = processor.decode(
        outputs.sequences[0, inputs["input_ids"].shape[1]:],
        skip_special_tokens=True,
    )

if use_thinking:
    _, separator, text = text.partition("</think>")
    if not separator:
        raise RuntimeError("Reasoning has not finished; increase max_new_tokens.")
print(text.strip())
```

**Output** (truncated)

```text
It is completely normal to feel nervous before a job interview, but you can definitely manage it. The key is to shift your focus from "what could go wrong" to "what I can control."

Here are some practical tips to calm your nerves for tomorrow morning:

**1. Physical Relaxation**
*   **Deep Breathing:** Take a few deep breaths. Try the "box breathing" method: inhale for 4 seconds, hold for 4, exhale for 4, and hold for 4. This signals to your nervous system that your body is safe.
*   **Stretch Out:** Tense shoulders, neck, and jaw are the primary culprits of interview anxiety. Take a minute to stretch—roll your shoulders back, gently tilt your head side-to-side, and shake out your hands.
...
```

## Audio understanding

Include the recording and a question in the user turn. Questions can address speech, music, background sounds, or events. No specific system prompt is required. To ground answers in the recording, use `Answer questions about the provided audio clip. Base every answer only on what can be heard.` This example asks about the speaker in the LibriSpeech recording.

```python
conversation = [
    {
        "role": "system",
        "content": "Answer questions about the provided audio clip. Base every answer only on what can be heard.",
    },
    {
        "role": "user",
        "content": [
            {"type": "audio", "audio": "librispeech.wav"},
            {"type": "text", "text": "Who or what is the speaker talking about, and what is their attitude towards it?"},

    },
    {"role": "assistant", "content": "<think></think>"},
]

inputs = processor.apply_chat_template(
    conversation,
    continue_final_message=True,
    tokenize=True,
    return_dict=True,

).to(device)

with torch.no_grad():
    outputs = model.generate(
        **inputs,
        max_new_tokens=1024,
        suppress_mixed=True,
        suppress_audio_out=True,
        return_dict_in_generate=True,

print(processor.decode(
    outputs.sequences[0, inputs["input_ids"].shape[1]:],

```

## Tool calling

Pass function schemas through `tools=...` to `apply_chat_template()`. The chat template inserts the definitions into the system prompt in the LFM3 format. Requests may be spoken or written, and the example below sends the spoken weather question and asks for a text response.

```python
tools = [
    {
        "type": "function",
        "function": {
            "name": "set_alarm",
            "description": "Sets an alarm at a given time.",
            "parameters": {
                "type": "object",
                "properties": {
                    "time": {"type": "string", "description": "Time in 24h HH:MM format."},
                    "label": {"type": "string", "description": "Optional label for the alarm."},
                },
                "required": ["time"],
            },
        },
    },
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "Returns the current weather for a city.",
            "parameters": {"type": "object", "properties": {"city": {"type": "string"}}, "required": ["city"]},
        },
    },
]

conversation = [
    {"role": "user", "content": [{"type": "audio", "audio": "request.wav"}]},
    {"role": "assistant", "content": "<think></think>"},
]

inputs = processor.apply_chat_template(
    conversation,
    tools=tools,
    continue_final_message=True,
    tokenize=True,
    return_dict=True,
    return_tensors="pt",
).to(device)

with torch.no_grad():
    outputs = model.generate(
        **inputs,
        max_new_tokens=1024,
        suppress_mixed=True,
        suppress_audio_out=True,
        return_dict_in_generate=True,
    )

print(processor.decode(
    outputs.sequences[0, inputs["input_ids"].shape[1]:],
    skip_special_tokens=False,
))
```

**Output**

```text
<tool_call>
<function=get_weather>
<parameter=city>
Edinburgh
</parameter>
</function>
</tool_call><|im_end|>
```

Generated calls use the LFM3 `<tool_call>` XML format. Your application parses and executes the call, adds the assistant's `tool_calls` to the conversation, and returns the result as a `tool` message. Pass the tool schemas on subsequent turns. See [Tool Use](/lfm/key-concepts/tool-use) for the full workflow.

## Images with spoken questions

<Info>**Model support:** This capability requires LFM3-Omni-2B.</Info>

LFM3-Omni-2B takes images, video, and audio in a single model. Load it with `AutoModelForImageTextToText`. Its processor bundles the audio codec, and audio files are resampled to 16 kHz mono on load. The helper below renders the conversation, generates, and returns the text reply and the speech, if any.

```python
import torch
from transformers import AutoModelForImageTextToText, AutoProcessor

OMNI_MODEL_ID = "LiquidAI/LFM3-Omni-2B"
omni_processor = AutoProcessor.from_pretrained(OMNI_MODEL_ID, trust_remote_code=True)
omni_model = AutoModelForImageTextToText.from_pretrained(
    OMNI_MODEL_ID, dtype=torch.bfloat16, device_map="cuda", trust_remote_code=True
)
omni_codec = omni_processor.audio_tokenizer.to(omni_model.device)

@torch.inference_mode()
def omni_generate(conversation, generation_mode=None, max_new_tokens=512, **processor_kwargs):
    inputs = omni_processor.apply_chat_template(
        conversation, add_generation_prompt=True, tokenize=True, return_dict=True, return_tensors="pt",
        processor_kwargs=processor_kwargs,
    ).to(omni_model.device)
    out = omni_model.generate(
        **inputs, max_new_tokens=max_new_tokens, generation_mode=generation_mode,
        audio_temperature=0.4, audio_repetition_penalty=1.2,
    )
    prompt_len = inputs["input_ids"].shape[1]
    reply = omni_processor.decode(out.sequences[0, prompt_len : out.sequence_lengths[0]], skip_special_tokens=True)
    speech = None
    if out.audio_lengths[0] > 0:
        speech = omni_codec.decode(out.audio_codes[:1, :, : out.audio_lengths[0]]).audio_values[0].float().cpu().numpy().squeeze()
    return reply, speech
```

Images are processed at their native resolution. Use the system prompt `Describe the provided image.` for captions.


## Video with soundtrack

<Info>**Model support:** This capability requires LFM3-Omni-2B.</Info>

LFM3-Omni-2B can answer questions that depend on both what is seen and what is heard in a video. Set `load_audio_from_video=True` and `use_audio_in_video=True`: the processor reads the video's audio track and interleaves it with the frames, so each pair of frames is followed by the sound that goes with it. Without the two flags, only the frames are used.

Video is sampled at 2 frames per second, consecutive frames are paired, and each pair is prefixed with its timestamp. This example asks about a short clip from the Hugging Face test videos, first with the frames only, then with the frames and the soundtrack.

```python
from huggingface_hub import hf_hub_download

video_path = hf_hub_download("raushan-testing-hf/videos-test", "sample_demo_1.mp4", repo_type="dataset")

@torch.inference_mode()
def ask_video(question, use_audio=False):
    extra = dict(load_audio_from_video=True, processor_kwargs={"use_audio_in_video": True}) if use_audio else {}
    inputs = omni_processor.apply_chat_template(
        [
            {"role": "system", "content": "Answer questions about the video using what you see and hear."},
            {"role": "user", "content": [{"type": "video", "video": video_path}, {"type": "text", "text": question}]},
        ],
        add_generation_prompt=True, tokenize=True, return_dict=True, return_tensors="pt", **extra,
    ).to(omni_model.device)
    out = omni_model.generate(**inputs, max_new_tokens=256, generation_mode="text")
    return omni_processor.decode(out.sequences[0, inputs["input_ids"].shape[1]:], skip_special_tokens=True)

print("Frames only:\n", ask_video("What happens in this video?"))
print("\nFrames and soundtrack:\n", ask_video("What happens in this video, and what can you hear?", use_audio=True))
```

## Output modality

<Info>**Model support:** This capability requires LFM3-Omni-2B.</Info>

LFM3-Omni-2B chooses its output modality from the system prompt. Pass `generation_mode="text"`, `"audio"`, or `"interleaved"` to override it. Use `"audio"` (speech only) for reading text aloud and speech-to-speech translation, and prefer `"interleaved"` for open-ended spoken answers. This example answers the same question in text and in interleaved text and speech.

```python
conversation = [
    {"role": "user", "content": [{"type": "image", "image": "bee.jpg"}, {"type": "text", "text": "Describe this picture in one sentence."}]},
]
for mode in ["text", "interleaved"]:
    torch.manual_seed(0)
    reply, speech = omni_generate(conversation, generation_mode=mode)
    print(f"{mode}: {reply}")
```

**Output**

## FAQ

**Which model should I use?**

Use `LFM3-Audio-2B` for speech and audio tasks: transcription, speech synthesis, voice chat, translation, audio understanding, and spoken tool calls. Use `LFM3-Omni-2B` when the request also involves images or video, such as spoken questions about a photo or questions about a video and its soundtrack.

**What audio input is supported?**

Both models take audio at 16 kHz. LFM3-Omni-2B resamples audio files to 16 kHz mono on load. Speech output is a 24 kHz waveform.

**Can the models stream speech?**

Yes. LFM3-Audio-2B uses a causal audio encoder that supports live audio input and incremental prefill, and its audio codec supports streaming encoding and decoding. In Transformers, pass `streamer` and `audio_streamer` to `model.generate()`.

**Do the models reason before answering?**

LFM3-Audio-2B reasons before text-only answers when you prefill `<think>`, and answers directly with `<think></think>`. LFM3-Omni-2B is a non-reasoning model.

**Why should I always sample speech output?**

With LFM3-Omni-2B, greedy audio decoding degenerates, so always pass `audio_temperature` for speech or interleaved output. In Transformers, generation decodes audio greedily when `audio_temperature` is not set. Text output works with greedy decoding.
