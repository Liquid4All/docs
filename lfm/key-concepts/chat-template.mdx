A chat template turns a conversation into the text the model reads. The examples below show how the template formats messages and generation prompts.

Conversations are formatted using special tokens:

| Special token | Meaning |
|---|---|
| `<\|startoftext\|>` | Start of the conversation. |
| `<\|im_start\|>` | Start of the message. Always followed by the role name (`system`, `user`, `assistant`, or `tool`) and a line break. |
| `<\|im_end\|>` | End of the message. |
| `<think>` / `</think>` | Start and end of the model's reasoning, at the beginning of an assistant turn. See [Thinking](/lfm/key-concepts/thinking). |

LFM models support four conversation roles:

* **`system`** — (Optional) Defines who the assistant is and how it should respond.
* **`user`** — Messages from the user containing questions and instructions.
* **`assistant`** — Responses from the model.
* **`tool`** — Results from tool/function execution. Used for [tool use](/lfm/key-concepts/tool-use) workflows.

The complete chat template definition can be found in the `chat_template.jinja` file in each model's Hugging Face repository.

## Text Models

We recommend storing your conversation as a list of dictionaries as follows:

```python
messages = [
    {"role": "system", "content": "You are a helpful assistant trained by Liquid AI."},
    {"role": "user", "content": "What is C. elegans?"}
]
```

You can then apply the model's chat template using the [`.apply_chat_template()`](https://huggingface.co/docs/transformers/main/en/chat_templating#using-applychattemplate) method from Transformers:

<Tabs>
<Tab title="LFM3">

```python
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("LiquidAI/LFM3-1.7B", trust_remote_code=True)

# Apply chat template
prompt = tokenizer.apply_chat_template(
    messages,
    tokenize=False,
    add_generation_prompt=True
)
print(prompt)
```

**Output**

</Tab>

## Vision Models

Vision models follow the same chat template with additional support for images. When creating conversations for vision models, use a structured format with `content` as a list containing image and text entries. You can then apply the chat template using the processor's `.apply_chat_template()` method.

<Tabs>
<Tab title="LFM3">

| Special token | Meaning |
|---|---|
| `<\|vision_start\|><\|image\|><\|vision_end\|>` | Each image is rendered as these tokens. |
| `<\|vision_start\|><\|video\|><\|vision_end\|>` | Each video is rendered as these tokens. |

The processor's `.apply_chat_template()` method inserts these tokens automatically, so do not include them in your message content.

```python
from transformers import AutoProcessor

processor = AutoProcessor.from_pretrained("LiquidAI/LFM3-VL-2B", trust_remote_code=True)

messages = [
    {"role": "system", "content": "You are a helpful assistant trained by Liquid AI."},
    {
        "role": "user",
        "content": [
            {"type": "image", "url": "http://images.cocodataset.org/val2017/000000039769.jpg"},
            {"type": "text", "text": "What species is in this picture?"},
        ],
    },
]

# Apply chat template
prompt = processor.apply_chat_template(
    messages,
    tokenize=False,
    add_generation_prompt=True
)
print(prompt)
```

**Output**

```text
<|startoftext|><|im_start|>system
You are a helpful assistant trained by Liquid AI.<|im_end|>
<|im_start|>user
<|vision_start|><|image|><|vision_end|>What species is in this picture?<|im_end|>
<|im_start|>assistant
<think>
```

</Tab>
<Tab title="LFM2/LFM2.5">

| Special token | Meaning |
|---|---|
| `<image>` | When formatted, images are represented with this sentinel token, which is automatically replaced with image tokens by the processor. |

## Audio and Omni Models

Audio and omni models follow the same chat template. The processor's `.apply_chat_template()` method inserts the audio tokens for you.

| Special token | Meaning |
|---|---|
| `<\|audio\|>` | An input audio clip. Depending on the model, it sits inside a `<\|vision_start\|>` / `<\|vision_end\|>` span, like images and video. |
| `<\|audio_start\|>` | Opens speech in the answer. |
| `<\|mixed_start\|>` | Opens interleaved text and speech in the answer. |
| `<think></think>` | Empty block that the template of a non-reasoning model opens every assistant turn with. |

For example, an audio model and an omni model can format the same audio transcription request:

```python
messages = [
    {"role": "system", "content": "Perform ASR in English."},
    {"role": "user", "content": [{"type": "audio", "audio": "speech.wav"}]},
]
```

<Tabs>
<Tab title="LFM3-Audio">

```python
from transformers import AutoProcessor

processor = AutoProcessor.from_pretrained("LiquidAI/LFM3-Audio-2B", trust_remote_code=True)

# Apply chat template
prompt = processor.apply_chat_template(
    messages,
    tokenize=False,
    add_generation_prompt=True,
)
print(prompt)
```

**Output**

```text
<|startoftext|><|im_start|>system
Perform ASR in English.<|im_end|>
<|im_start|>user
<|audio|><|im_end|>
<|im_start|>assistant
```
