d1-3B is a 3.1B parameter decision model built on [LFM2.5-VL-3B](/lfm/models/lfm25-vl-3b). It evaluates text, JSON, images, or a mix and returns calibrated Noul, Choice, and Score answers in one forward pass with zero output tokens.

| Architecture | LFM2.5-VL (Dense) — LFM2.5-2.6B backbone + SigLIP2 NaFlex 400M vision encoder |

## Quick Start

<Tabs>
  <Tab title="Transformers">
    **Install:**

    ```bash
    pip install "transformers>=5.14" torch accelerate torchvision pillow
    ```

    **Text input:**

    ```python
    from transformers import AutoModel

    model_id = "LiquidAI/d1-3B"
    model = AutoModel.from_pretrained(model_id, trust_remote_code=True, dtype="bfloat16", device_map="auto")

    state = "I was charged twice this month, please refund one of them."
    questions = {
        "refund": {"type": "noul", "instructions": "Is the customer asking for a refund?"},
        "team": {"type": "choice", "instructions": "Which team should handle this?",
                 "criteria": {"billing": "Charges, refunds, invoices", "technical": "App or site faults",
                              "fraud": "Suspected unauthorised use"}},
        "urgency": {"type": "score", "instructions": "How urgent is this?",
                    "criteria": ["Can wait", "Today", "Blocking the customer now"]},
    }
    output = model.system_one(state, questions)
    print(output)
    ```

    **Image input:**

    ```python
    import io
    import urllib.request

    from PIL import Image
    from transformers import AutoModel

    model_id = "LiquidAI/d1-3B"
    model = AutoModel.from_pretrained(model_id, trust_remote_code=True, dtype="bfloat16", device_map="auto")

    url = "http://images.cocodataset.org/val2017/000000039769.jpg"
    photo = Image.open(io.BytesIO(urllib.request.urlopen(url).read()))

    questions = {"cats": {"type": "choice", "instructions": "How many cats are there?",
                          "criteria": {"one": "One", "two": "Two", "more": "Three or more"}}}
    output = model.system_one(None, questions, images=[photo])
    print(output)
    ```

## Other Formats

- **MLX**: [d1-3B-MLX-8bit](https://huggingface.co/LiquidAI/d1-3B-MLX-8bit), [d1-3B-MLX-4bit](https://huggingface.co/LiquidAI/d1-3B-MLX-4bit), and [d1-3B-MLX-fp16](https://huggingface.co/LiquidAI/d1-3B-MLX-fp16) run on Apple Silicon with [mlx-vlm](https://github.com/Blaizzy/mlx-vlm). d1 support landed after mlx-vlm 0.7.6, so install mlx-vlm from GitHub until the next release. See the model cards for Python, CLI, and server usage.
- **W8A8**: [d1-3B-w8a8](https://huggingface.co/LiquidAI/d1-3B-w8a8) is an INT8 (weights and activations) version for NVIDIA GPUs with INT8 tensor cores, from Ampere on, including Jetson devices. It needs `transformers>=5.19` and `torchao>=0.18`, and is 3.8 GB instead of 6.2 GB for the bf16 checkpoint. On other hardware, use d1-3B. See the [model card](https://huggingface.co/LiquidAI/d1-3B-w8a8) for setup.
