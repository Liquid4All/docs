LFM2.5-24B-A2B is the largest LFM2.5 model, a Mixture-of-Experts model combining 24B total parameters with only 2B active parameters per token and a 131K context window. It is a reasoning model that always thinks before it answers, post-trained for tool calling and multi-step agentic tasks on-device.

## Specifications

| Property | Value |
|----------|-------|
| Parameters | 24B (2B active) |
| Context Length | 131K tokens |
| Architecture | LFM2.5 (MoE), 40 layers (30 gated short convolution + 10 GQA), 64 experts per MoE block with top-4 routing |
| Vocabulary Size | 128K |
| Languages | English, Arabic, Chinese, French, German, Italian, Japanese, Korean, Portuguese, Spanish, Vietnamese, Thai, Indonesian, Hindi, Russian, Polish |
| Generation Parameters | `temperature=0.1`, `top_k=50`, `repetition_penalty=1.05` |

## Quick Start

<Tabs>
  <Tab title="Transformers">
    Install:

    ```bash
    pip install "transformers>=5.0.0" torch accelerate
    ```

    Run:

    ```python
    from transformers import AutoModelForCausalLM, AutoTokenizer, TextStreamer

    model_id = "LiquidAI/LFM2.5-24B-A2B"
    model = AutoModelForCausalLM.from_pretrained(
        model_id,
        device_map="auto",
        dtype="bfloat16",
    #   attn_implementation="flash_attention_2" <- uncomment on compatible GPU
    )
    tokenizer = AutoTokenizer.from_pretrained(model_id)
    streamer = TextStreamer(tokenizer, skip_prompt=True, skip_special_tokens=True)

    prompt = "What is C. elegans?"

    input_ids = tokenizer.apply_chat_template(
        [{"role": "user", "content": prompt}],
        add_generation_prompt=True,
        return_tensors="pt",
        tokenize=True,
    )["input_ids"].to(model.device)

    output = model.generate(
        input_ids,
        do_sample=True,
        temperature=0.1,
        top_k=50,
        repetition_penalty=1.05,
        max_new_tokens=4096,
        streamer=streamer,
    )
    ```

    from mlx_lm import load, generate

    model, tokenizer = load("LiquidAI/LFM2.5-24B-A2B-MLX-4bit")

## Reasoning

Unlike LFM2-24B-A2B, LFM2.5-24B-A2B always thinks before it answers. The chat template opens every assistant turn with a `<think>` tag, so responses contain an explicit chain of thought before the final answer. Leave enough room in your max token budget for the reasoning trace. See [Chat Template](/lfm/key-concepts/chat-template) and [Tool Use](/lfm/key-concepts/tool-use) for the message format.

## FP8 Checkpoint

[LFM2.5-24B-A2B-FP8](https://huggingface.co/LiquidAI/LFM2.5-24B-A2B-FP8) is an FP8 version of LFM2.5-24B-A2B for high-throughput GPU serving with vLLM and SGLang at lower memory usage. Linear weights are quantized to FP8 with 128×128 blocks and dynamic activation quantization; the embedding, MoE routing gates, and convolution weights stay in their original precision. To use it, replace the model ID in the vLLM or SGLang examples above with `LiquidAI/LFM2.5-24B-A2B-FP8`.
