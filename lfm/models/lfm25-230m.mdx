LFM2.5-230M is Liquid AI's smallest LFM2.5 text model, designed for edge devices with the tightest memory and compute budgets. Built on the LFM2.5 architecture, it is tuned for data extraction and lightweight on-device agentic tasks such as tool calling. It is not recommended for reasoning-heavy workloads like advanced math, code generation, or creative writing — start with [LFM3-1.7B](/lfm/models/lfm3-1.7b) and evaluate it on those tasks. LFM2.5-350M is another compact option for extraction and agents, not a programming-model recommendation.

## Quick Start

  <Tab title="Transformers">
    {/* quickstart: {"source":"/snippets/quickstart/text-transformers.mdx","component":"TextTransformers","props":{"modelId":"LiquidAI/LFM2.5-230M","samplingParams":"do_sample=True, temperature=0.1, top_k=50, repetition_penalty=1.05, "}} */}
**Install:**

```bash
pip install "transformers==5.23.0" torch accelerate
```

**Download & Run:**

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_id = "LiquidAI/LFM2.5-230M"
model = AutoModelForCausalLM.from_pretrained(
    model_id,
    device_map="auto",
    dtype="bfloat16",
)
tokenizer = AutoTokenizer.from_pretrained(model_id)

inputs = tokenizer.apply_chat_template(
    [{"role": "user", "content": "What is machine learning?"}],
    add_generation_prompt=True,
    return_tensors="pt",
    tokenize=True,
    return_dict=True,
).to(model.device)

output = model.generate(**inputs, do_sample=True, temperature=0.1, top_k=50, repetition_penalty=1.05, max_new_tokens=512)
input_length = inputs["input_ids"].shape[1]
response = tokenizer.decode(output[0][input_length:], skip_special_tokens=True)
print(response)
```

```python
from vllm import LLM, SamplingParams

llm = LLM(model="LiquidAI/LFM2.5-230M", enforce_eager=True)

sampling_params = SamplingParams(temperature=0.1, top_k=50, repetition_penalty=1.05, max_tokens=512)

output = llm.chat([{"role": "user", "content": "What is machine learning?"}], sampling_params)
print(output[0].outputs[0].text)
```

**Query (OpenAI-compatible):**

```python
from openai import OpenAI

client = OpenAI(base_url="http://localhost:30000/v1", api_key="None")

response = client.chat.completions.create(
    model="LiquidAI/LFM2.5-230M",
    messages=[{"role": "user", "content": "What is machine learning?"}],
    temperature=0.1,
    extra_body={"top_k": 50, "repetition_penalty": 1.05},
)

print(response.choices[0].message.content)
```
