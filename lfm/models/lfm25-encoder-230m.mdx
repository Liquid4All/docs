LFM2.5-Encoder-230M is a multilingual bidirectional encoder built on the LFM2 architecture. At 230M parameters, it is designed to be fine-tuned into task-specific models (classification, token classification, retrieval, reranking, and semantic similarity) across 15 languages.

## Quick Start

<Note>
This is a base encoder that produces general-purpose representations.
For task outputs, fine-tune it with a task head for your use case. See [Fine-Tuning](#fine-tuning) below for recommended hyperparameters.
</Note>

<Tabs>
  <Tab title="Transformers">
    **Install:**
    ```bash
    pip install -U transformers torch
    ```

    **Run masked-token prediction:**
    ```python
    from transformers import AutoModelForMaskedLM, AutoTokenizer
    import torch

    tok = AutoTokenizer.from_pretrained("LiquidAI/LFM2.5-Encoder-230M", trust_remote_code=True)
    mlm = AutoModelForMaskedLM.from_pretrained("LiquidAI/LFM2.5-Encoder-230M", trust_remote_code=True)

    text = f"The capital of France is {tok.mask_token}."
    enc = tok(text, return_tensors="pt")
    with torch.no_grad():
        logits = mlm(**enc).logits
    pos = (enc["input_ids"][0] == tok.mask_token_id).nonzero()[0].item()
    print([tok.decode([t]).strip() for t in logits[0, pos].topk(5).indices.tolist()])
    # -> ['Paris', 'Strasbourg', 'Paris', 'Lyon', 'Versailles']
    ```

    **Load the encoder body for downstream tasks:**

    For classification, token classification, regression, or retrieval, load the encoder body and attach your own head:
    ```python
    from transformers import AutoModel

    body = AutoModel.from_pretrained("LiquidAI/LFM2.5-Encoder-230M", trust_remote_code=True)
    ```
  </Tab>

  <Tab title="llama.cpp">
    The GGUF checkpoint serves per-token embeddings (hidden states) through `llama-server`.

    **Start llama-server:**
    ```bash
    hf download LiquidAI/LFM2.5-Encoder-230M-GGUF LFM2.5-Encoder-230M-F16.gguf --local-dir .
    llama-server -m LFM2.5-Encoder-230M-F16.gguf --embeddings --pooling none
    ```

    **Get per-token embeddings** (in a separate shell):
    ```bash
    curl -s http://localhost:8080/embedding -d '{"content": "hello world"}'
    ```

    **Run masked-token prediction** with the `fill-mask.py` client from the GGUF repository:
    ```bash
    hf download LiquidAI/LFM2.5-Encoder-230M-GGUF fill-mask.py --local-dir .
    uv run fill-mask.py LFM2.5-Encoder-230M-F16.gguf "The capital of France is [MASK]."
    ```
  </Tab>
</Tabs>

## Fine-Tuning

LFM2.5-Encoder-230M follows standard BERT-style fine-tuning: attach a task head to the encoder body (`AutoModel`) and train end-to-end. The model card suggests these starting points, to tune per task:

| Hyperparameter | Suggested range |
|---|---|
| Learning rate | 1e-5 – 5e-5 |
| Warmup ratio | 0.1 |
| Weight decay | 0.1 |
| Epochs | 3 – 20 (early stopping, patience 3) |
| Precision | bf16 autocast (fp32 master weights) |

If your GPU supports it, install Flash Attention 2 (`pip install flash-attn`) for higher efficiency. For examples of fine-tuned encoders, see [LFM2.5-Encoder-350M-PII-Detector](https://huggingface.co/LiquidAI/LFM2.5-Encoder-350M-PII-Detector), [LFM2.5-Encoder-350M-Prompt-Router](https://huggingface.co/LiquidAI/LFM2.5-Encoder-350M-Prompt-Router), [LFM2.5-Encoder-350M-Policy-Linter](https://huggingface.co/LiquidAI/LFM2.5-Encoder-350M-Policy-Linter), and [LFM2.5-Encoder-350M-Spellchecker](https://huggingface.co/LiquidAI/LFM2.5-Encoder-350M-Spellchecker).
