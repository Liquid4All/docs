LFM2.5-8B-A1B is Liquid AI's Mixture-of-Experts reasoning model, combining 8B total parameters with only 1.5B active parameters per forward pass and a 128K context window. Assistant turns contain an explicit chain of thought before the final answer. It is designed for tool calling, instruction following, and agentic tasks on-device.

## Quick Start

<Tabs>
  <Tab title="Transformers">
    Install:

    ```bash
    pip install "transformers>=5.0.0" torch accelerate
    ```

    Run:

    ```python
    from transformers import AutoModelForCausalLM, AutoTokenizer, TextStreamer

    model_id = "LiquidAI/LFM2.5-8B-A1B"
    model = AutoModelForCausalLM.from_pretrained(
        model_id,
        device_map="auto",
        dtype="bfloat16",
    #   attn_implementation="flash_attention_2" <- uncomment on compatible GPU
    )
    tokenizer = AutoTokenizer.from_pretrained(model_id)
    streamer = TextStreamer(tokenizer, skip_prompt=True, skip_special_tokens=True)

    prompt = "What is C. elegans?"

    input_ids = tokenizer.apply_chat_template(
        [{"role": "user", "content": prompt}],
        add_generation_prompt=True,
        return_tensors="pt",
        tokenize=True,
    )["input_ids"].to(model.device)

    output = model.generate(
        input_ids,
        do_sample=True,
        temperature=0.2,
        top_k=80,
        repetition_penalty=1.05,
        max_new_tokens=8192,
        streamer=streamer,
    )
    ```

## Speculative Decoding

[LFM2.5-8B-A1B-DSpark](https://huggingface.co/LiquidAI/LFM2.5-8B-A1B-DSpark) is a 328M draft model for speculative decoding with LFM2.5-8B-A1B. The target model verifies every drafted token, so outputs are identical to running LFM2.5-8B-A1B alone, and decoding runs about 2.5x faster in SGLang. Use it with SGLang (requires DSpark support for LFM2-MoE targets, [PR #31041](https://github.com/sgl-project/sglang/pull/31041)) or with llama.cpp through [LFM2.5-8B-A1B-DSpark-GGUF](https://huggingface.co/LiquidAI/LFM2.5-8B-A1B-DSpark-GGUF), a draft sidecar that must be paired with an [LFM2.5-8B-A1B-GGUF](https://huggingface.co/LiquidAI/LFM2.5-8B-A1B-GGUF) target. See the model cards for launch commands.
