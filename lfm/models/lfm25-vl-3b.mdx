LFM2.5-VL-3B is the largest vision-language model in the LFM2.5 family, with grounding, screen and document understanding, and function calling. It builds on LFM2-VL-3B with further mid- and post-training, pairs the LFM2.5-2.6B language backbone with a SigLIP2 NaFlex shape-optimized 400M vision encoder, and answers directly without a reasoning trace for low-latency inference on-device and in the cloud.

For new applications, start with [LFM3-VL-2B](/lfm/models/lfm3-vl-2b), which adds video input and reasoning. Keep this model when its direct-answer behavior or tested deployment fits your task better.

## Quick Start

<Tabs>
  <Tab title="Transformers">
    {/* quickstart: {"source":"/snippets/quickstart/vl-transformers.mdx","component":"VlTransformers","props":{"modelId":"LiquidAI/LFM2.5-VL-3B","samplingArgs":"temperature=0.2, top_k=50, repetition_penalty=1.0"}} */}
**Install:**

```bash
pip install "transformers==5.23.0" pillow torch torchvision accelerate
```

**Download & Run:**

```python
from transformers import AutoProcessor, AutoModelForImageTextToText
from transformers.image_utils import load_image

model_id = "LiquidAI/LFM2.5-VL-3B"
model = AutoModelForImageTextToText.from_pretrained(
    model_id,
    device_map="auto",
    dtype="bfloat16",
)

processor = AutoProcessor.from_pretrained(model_id)

url = "https://cdn.britannica.com/61/93061-050-99147DCE/Statue-of-Liberty-Island-New-York-Bay.jpg"
image = load_image(url)

conversation = [
    {
        "role": "user",
        "content": [
            {"type": "image", "image": image},
            {"type": "text", "text": "What is in this image?"},
        ],
    },
]

inputs = processor.apply_chat_template(
    conversation,
    add_generation_prompt=True,
    return_tensors="pt",
    return_dict=True,
    tokenize=True,
).to(model.device)

outputs = model.generate(**inputs, do_sample=True, temperature=0.2, top_k=50, repetition_penalty=1.0, max_new_tokens=256)
input_length = inputs["input_ids"].shape[1]
response = processor.batch_decode(outputs[:, input_length:], skip_special_tokens=True)[0]
print(response)
```

## Speculative Decoding

<Tabs>
  <Tab title="SGLang">
    {/* quickstart: {"source":"/snippets/quickstart/dspark-sglang.mdx","component":"DsparkSglang","props":{"modelId":"LiquidAI/LFM2.5-VL-3B","draftModelId":"LiquidAI/LFM2.5-VL-3B-DSpark","vision":true,"samplingParams":"temperature=0.2,\n    extra_body={\"top_k\": 50, \"repetition_penalty\": 1.0},"}} */}
**Install:**

Requires [SGLang v0.5.19](https://github.com/sgl-project/sglang/releases/tag/v0.5.19) or newer.

**Launch server with the drafter attached:**

```bash
python -m sglang.launch_server \
    --model-path LiquidAI/LFM2.5-VL-3B \
    --speculative-algorithm DSPARK \
    --speculative-draft-model-path LiquidAI/LFM2.5-VL-3B-DSpark \
    --speculative-draft-attention-backend flashinfer \
    --speculative-dspark-block-size 9 \
    --disable-radix-cache --mem-fraction-static 0.8 --port 30000
```

**Query (OpenAI-compatible):**

```python
from openai import OpenAI

client = OpenAI(base_url="http://localhost:30000/v1", api_key="None")

response = client.chat.completions.create(
    model="LiquidAI/LFM2.5-VL-3B",
    messages=[{
        "role": "user",
        "content": [
            {"type": "image_url", "image_url": {"url": "http://images.cocodataset.org/val2017/000000039769.jpg"}},
            {"type": "text", "text": "Describe what you see in this image."},
        ],
    }],
    temperature=0.2,
    extra_body={"top_k": 50, "repetition_penalty": 1.0},
)

print(response.choices[0].message.content)
```

**Flags:**

- `--speculative-algorithm DSPARK`: turns on DSpark speculative decoding.
- `--speculative-draft-model-path`: the drafter repo on Hugging Face, or a local path.
- `--speculative-draft-attention-backend flashinfer`: the attention backend the drafter runs on.
- `--speculative-dspark-block-size`: how many tokens the drafter proposes per step. Use 9, the block size the drafter was trained with.
- `--disable-radix-cache`: turns off SGLang's prefix cache, as in the drafter's model card.
- `--mem-fraction-static`: the share of GPU memory SGLang reserves for weights and the KV cache.

**Install:**

```bash
brew install llama.cpp
```

DSpark needs a recent build. Check that `llama serve --help` lists `draft-dspark` under `--spec-type`.

**Run the target with the draft sidecar:**

```bash
llama serve \
    -hf LiquidAI/LFM2.5-VL-3B-GGUF:F16 \
    -hfd LiquidAI/LFM2.5-VL-3B-DSpark-GGUF:F16 \
    --spec-type draft-dspark --spec-draft-n-max 8 --spec-draft-n-min 0 \
    -ngl 99 -ngld 99 -fa on \
    --temp 0.2 --top-k 50 --repeat-penalty 1.0
```

**Flags:**

- `-hf`: the target GGUF on Hugging Face, with its quantization tag. Use `-m` for a local file.
- `-hfd`: the draft sidecar GGUF. Use `-md` for a local file. The sidecar has no embeddings or LM head, so it cannot run on its own.
- `--spec-type draft-dspark`: turns on DSpark speculative decoding.
- `--spec-draft-n-max`: the most tokens the drafter proposes per step. The drafter was trained with block size 9. Use 8 on Apple silicon.
- `--spec-draft-n-min`: the fewest tokens the drafter proposes per step.
- `-ngl 99` / `-ngld 99`: offload all target and drafter layers to the GPU.
- `-fa on`: turns on flash attention.
