## Quick Start

<Tabs>
  <Tab title="Transformers">
    {/* quickstart: {"source":"/snippets/quickstart/text-transformers.mdx","component":"TextTransformers","props":{"modelId":"LiquidAI/LFM2.5-1.2B-Instruct","samplingParams":"do_sample=True, temperature=0.1, top_k=50, repetition_penalty=1.05, "}} */}
**Install:**

```bash
pip install "transformers==5.23.0" torch accelerate
```

**Download & Run:**

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_id = "LiquidAI/LFM2.5-1.2B-Instruct"
model = AutoModelForCausalLM.from_pretrained(
    model_id,
    device_map="auto",
    dtype="bfloat16",
)
tokenizer = AutoTokenizer.from_pretrained(model_id)

inputs = tokenizer.apply_chat_template(
    [{"role": "user", "content": "What is machine learning?"}],
    add_generation_prompt=True,
    return_tensors="pt",
    tokenize=True,
    return_dict=True,
).to(model.device)

output = model.generate(**inputs, do_sample=True, temperature=0.1, top_k=50, repetition_penalty=1.05, max_new_tokens=512)
input_length = inputs["input_ids"].shape[1]
response = tokenizer.decode(output[0][input_length:], skip_special_tokens=True)
print(response)
```

## Speculative Decoding

<Tabs>
  <Tab title="SGLang">
    {/* quickstart: {"source":"/snippets/quickstart/dspark-sglang.mdx","component":"DsparkSglang","props":{"modelId":"LiquidAI/LFM2.5-1.2B-Instruct","draftModelId":"LiquidAI/LFM2.5-1.2B-Instruct-DSpark","samplingParams":"temperature=0.1,\n    extra_body={\"top_k\": 50, \"repetition_penalty\": 1.05},"}} */}
**Install:**

Requires a build of SGLang with DSpark support for LFM2 and LFM2-MoE targets ([PR #31041](https://github.com/sgl-project/sglang/pull/31041)).

**Launch server with the drafter attached:**

```bash
python -m sglang.launch_server \
    --model-path LiquidAI/LFM2.5-1.2B-Instruct \
    --speculative-algorithm DSPARK \
    --speculative-draft-model-path LiquidAI/LFM2.5-1.2B-Instruct-DSpark \
    --speculative-draft-attention-backend flashinfer \
    --disable-radix-cache --mem-fraction-static 0.75 --port 30000
```

**Query (OpenAI-compatible):**

```python
from openai import OpenAI

client = OpenAI(base_url="http://localhost:30000/v1", api_key="None")

response = client.chat.completions.create(
    model="LiquidAI/LFM2.5-1.2B-Instruct",
    messages=[{"role": "user", "content": "What is machine learning?"}],
    temperature=0.1,
    extra_body={"top_k": 50, "repetition_penalty": 1.05},
)

print(response.choices[0].message.content)
```

**Flags:**

- `--speculative-algorithm DSPARK`: turns on DSpark speculative decoding.
- `--speculative-draft-model-path`: the drafter repo on Hugging Face, or a local path.
- `--speculative-draft-attention-backend flashinfer`: the attention backend the drafter runs on.
- Block size: read from the drafter's `config.json`, so you don't need to set it.
- `--disable-radix-cache`: turns off SGLang's prefix cache, as in the drafter's model card.
- `--mem-fraction-static`: the share of GPU memory SGLang reserves for weights and the KV cache.

  <Tab title="llama.cpp">
    {/* quickstart: {"source":"/snippets/quickstart/dspark-llamacpp.mdx","component":"DsparkLlamacpp","props":{"ggufRepo":"LiquidAI/LFM2.5-1.2B-Instruct-GGUF","draftRepo":"LiquidAI/LFM2.5-1.2B-Instruct-DSpark-GGUF","samplingFlags":"--temp 0.1 --top-k 50 --repeat-penalty 1.05"}} */}
**Install:**

```bash
brew install llama.cpp
```

DSpark needs a recent build. Check that `llama serve --help` lists `draft-dspark` under `--spec-type`.

**Run the target with the draft sidecar:**

```bash
llama serve \
    -hf LiquidAI/LFM2.5-1.2B-Instruct-GGUF:F16 \
    -hfd LiquidAI/LFM2.5-1.2B-Instruct-DSpark-GGUF:F16 \
    --spec-type draft-dspark --spec-draft-n-max 10 --spec-draft-n-min 0 \
    -ngl 99 -ngld 99 -fa on \
    --temp 0.1 --top-k 50 --repeat-penalty 1.05
```

**Flags:**

- `-hf`: the target GGUF on Hugging Face, with its quantization tag. Use `-m` for a local file.
- `-hfd`: the draft sidecar GGUF. Use `-md` for a local file. The sidecar has no embeddings or LM head, so it cannot run on its own.
- `--spec-type draft-dspark`: turns on DSpark speculative decoding.
- `--spec-draft-n-max`: the most tokens the drafter proposes per step. llama.cpp clamps it to the drafter's block size.
- `--spec-draft-n-min`: the fewest tokens the drafter proposes per step.
- `-ngl 99` / `-ngld 99`: offload all target and drafter layers to the GPU.
- `-fa on`: turns on flash attention.
