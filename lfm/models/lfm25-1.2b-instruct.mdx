## Speculative Decoding

[LFM2.5-1.2B-Instruct-DSpark](https://huggingface.co/LiquidAI/LFM2.5-1.2B-Instruct-DSpark) is a 296M draft model for speculative decoding with LFM2.5-1.2B-Instruct. The target model verifies every drafted token, so outputs are identical to running LFM2.5-1.2B-Instruct alone. Decoding runs about 2.1x faster in SGLang and about 2.5x faster on Apple silicon. Use it with SGLang (requires DSpark support for LFM2 targets, [PR #31041](https://github.com/sgl-project/sglang/pull/31041)) or with llama.cpp through [LFM2.5-1.2B-Instruct-DSpark-GGUF](https://huggingface.co/LiquidAI/LFM2.5-1.2B-Instruct-DSpark-GGUF), a draft sidecar that must be paired with an [LFM2.5-1.2B-Instruct-GGUF](https://huggingface.co/LiquidAI/LFM2.5-1.2B-Instruct-GGUF) target. See the model cards for launch commands.
