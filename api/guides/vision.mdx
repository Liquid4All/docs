Vision models read images sent in a chat message, so they can describe a photo, read a screenshot or chart, or answer questions about a document page. Send images to `lfm3-vl-2b` or `lfm3-omni-2b` through [chat completions](/api/guides/text-generation), as `image_url` parts of a user message, the same way as OpenAI.

<CodeGroup>

```python Python
import os

from openai import OpenAI

client = OpenAI(api_key=os.environ["LIQUID_API_KEY"], base_url="https://api.liquid.ai/openai/v1")

completion = client.chat.completions.create(
    model="lfm3-vl-2b",
    messages=[
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "What is in this image?"},
                {
                    "type": "image_url",
                    "image_url": {"url": "https://upload.wikimedia.org/wikipedia/commons/3/3a/Cat03.jpg"},
                },
            ],
        }
    ],
    temperature=0.1,
    extra_body={"top_k": 50, "repetition_penalty": 1.1},
)
print(completion.choices[0].message.content)
```


## Send an image

An `image_url` part takes either an http(s) URL or a base64 `data:` URL. Prefer URLs for large images: a request body may be up to 4 MB, and base64 makes an image about a third larger.

Liquid downloads linked images itself before the request reaches the model, so each URL must be publicly reachable. A request may link up to 8 images, each a PNG, JPEG, WebP, or GIF of at most 10 MB, and 20 MB together. An image that can't be downloaded or isn't one of those formats returns `400`.

```python
import base64

with open("receipt.png", "rb") as f:
    image = base64.b64encode(f.read()).decode()

completion = client.chat.completions.create(
    model="lfm3-vl-2b",
    messages=[
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "What is the total on this receipt?"},
                {"type": "image_url", "image_url": {"url": f"data:image/png;base64,{image}"}},
            ],
        }
    ],
    temperature=0.1,
    extra_body={"top_k": 50, "repetition_penalty": 1.1},
)
```

A message can carry several images. Models that don't take images return `400`. See [Models](/api/models) for which models do.
