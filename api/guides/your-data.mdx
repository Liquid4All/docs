title: "Your data"
description: "How the Liquid API uses and retains your prompts, outputs, and usage data, including zero data retention (ZDR) endpoints."
---

How we handle your data depends on the endpoint you use.

## Direct online inference

The direct API endpoints `POST /openai/v1/chat/completions` and `POST /decisions/v1/systemone` use zero data retention (ZDR).

For these endpoints, we use request content, including prompts, system instructions, files, and responses, only to process and return the requested response. Other than temporary in-memory processing required to complete the request, we don't log, store, cache, or otherwise retain request content. Any temporary processing data is deleted when the request is complete. We don't use request content to train, fine-tune, evaluate, benchmark, or improve our models or services.

## Batch files and other surfaces

The Files and Batch APIs store uploaded inputs and generated outputs so asynchronous jobs can read them and you can download results. They are not covered by the online inference ZDR statement above. Do not treat a presigned file upload as temporary in-memory inference.

Console playgrounds and third-party platforms can have different data handling. Check the terms and data settings of the surface you use.

## Usage information

For all endpoints, we may keep basic usage information, such as token counts, latency, errors, and billing data, but not information that can reconstruct a request or response.

## Terms and privacy

The [Privacy Policy](https://www.liquid.ai/privacy-policy) explains how we handle personal data, including personal data contained in request content and usage information. Your use is also subject to our [Terms of Service](https://www.liquid.ai/terms-conditions) and any additional terms that apply to the service, endpoint, or platform you use.

If you access a Liquid model through a third-party platform, check the data information and terms shown for that endpoint on the platform.
