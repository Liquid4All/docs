Decision models answer typed questions about a state with calibrated probabilities instead of generated text. One request can ask several questions, and the model answers them all in a single forward pass with no generated tokens. Use them for classification, routing, scoring, yes/no gates, and reading values, passages, and objects from documents and pictures.

The endpoint, [`POST /decisions/v1/systemone`](/api/reference/decision-models/make-decisions), implements [TypeSafe's System One API](https://docs.typesafe.ai/api), so the official TypeSafe SDKs work with the base URL `https://api.liquid.ai/decisions`.

<CodeGroup>

```python Python
# pip install typesafe-sdk
import os

from typesafe_sdk import Choice, Noul, TypeSafeClient

client = TypeSafeClient(
    api_key=os.environ["LIQUID_API_KEY"],
    base_url="https://api.liquid.ai/decisions",
    model="d1.2",
)

response = client.system_one(
    state="Help! My payouts have been failing for 3 days.",
    questions={
        "department": Choice(
            instructions="Which team should handle this?",
            criteria={"billing": "Payments", "technical": "Bugs, outages", "sales": "Pricing"},
        ),
        "is_urgent": Noul(instructions="Does this convey urgency?"),
    },
)

print(response.answers["department"].choice, response.answers["is_urgent"].noul)
```

```typescript TypeScript
// npm install @typesafe-ai/sdk
import { TypeSafeClient, choice, noul } from "@typesafe-ai/sdk";

const client = new TypeSafeClient({
  apiKey: process.env.LIQUID_API_KEY,
  baseURL: "https://api.liquid.ai/decisions",
  defaultModel: "d1.2",
  compression: false, // the API doesn't accept zstd-compressed request bodies
});

const { answers } = await client.systemOne({
  state: "Help! My payouts have been failing for 3 days.",
  questions: {
    department: choice("Which team should handle this?", {
      billing: "Payments",
      technical: "Bugs, outages",
      sales: "Pricing",
    }),
    is_urgent: noul("Does this convey urgency?"),
  },
});

console.log(answers.department.choice, answers.department.confidence, answers.is_urgent.noul);
```

```bash cURL
curl https://api.liquid.ai/decisions/v1/systemone \
  -H "Authorization: Bearer $LIQUID_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "d1.2",
    "state": "Help! My payouts have been failing for 3 days.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this?",
        "criteria": { "billing": "Payments", "technical": "Bugs, outages", "sales": "Pricing" }
      },
      "is_urgent": { "type": "noul", "instructions": "Does this convey urgency?" }
    }
  }'
```

## Question types

| Type | Answers | Use it for |
| ---- | ------- | ---------- |
| Noul | One probability that the answer is yes. | Yes/no gates, moderation, flags. |
| Choice | The most likely option, its confidence, and the full distribution over options. | Classification and routing. |
| Score | The most likely level, its confidence, and the full distribution over ordered levels. | Rating and prioritization. |
| Choice with `multiple` | Every option that applies, each with its own probability. | Tagging and multi-label classification. |
| Text, Number, Date | A value read from the state, with the characters it came from, or "not found". | Extraction from documents, forms, and messages. |
| Number with `range` | An estimate with a likely range. | Counts and quantities. |
| Spans | Every passage of a kind in the state, with its position. | Redaction and highlighting. |
| Box, Boxes | A box around one object in the image, or every instance with a count. | Grounding and counting in pictures. |

Use the TypeSafe SDKs for Noul, Choice, and Score questions. They can't read the other answer types yet, so send typed questions, images, and audio over HTTP: see [Typed Answers](/lfm/models/d1#typed-answers).

## Models

| Model | Input | Use it for |
| ----- | ----- | ---------- |
| `d1.2-ultra` | Text, images, audio | Harder decisions. |
| `d1.2` | Text, images, audio | The default decision model. |

Both are billed on input tokens only, and output is free. A request is billed its state, images, and audio once, and each question adds its own tokens (its instructions, options, and answer slots). Requests may be up to 4.5 MB and 128 questions, and validation errors return `422`. `d1.1`, `d1-ultra`, and `d1` are [deprecated](/lfm/help/deprecations#deprecated-api-models).
