## Developer quickstart

Make your first request in minutes. The API speaks OpenAI's protocol, so the official OpenAI SDKs work with a new base URL.

<Card title="Get started" icon="rocket" href="/api/quickstart">

</CardGroup>

<CodeGroup>

```python Python
import os

from openai import OpenAI

client = OpenAI(api_key=os.environ["LIQUID_API_KEY"], base_url="https://api.liquid.ai/openai/v1")

completion = client.chat.completions.create(
    model="lfm3-1.7b",
    messages=[{"role": "user", "content": "Write a one-sentence bedtime story about a unicorn."}],
    temperature=0.1,
    extra_body={"top_k": 50, "repetition_penalty": 1.1},
)
print(completion.choices[0].message.content)
```

```javascript JavaScript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.LIQUID_API_KEY,
  baseURL: "https://api.liquid.ai/openai/v1",
});

const completion = await client.chat.completions.create({
  model: "lfm3-1.7b",
  messages: [{ role: "user", content: "Write a one-sentence bedtime story about a unicorn." }],
  temperature: 0.1,
  // top_k and repetition_penalty are Liquid extensions to the OpenAI API
  top_k: 50,
  repetition_penalty: 1.1,
});
console.log(completion.choices[0].message.content);
```

```bash cURL
curl https://api.liquid.ai/openai/v1/chat/completions \
  -H "Authorization: Bearer $LIQUID_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "lfm3-1.7b",
    "messages": [{"role": "user", "content": "Write a one-sentence bedtime story about a unicorn."}],
    "temperature": 0.1,
    "top_k": 50,
    "repetition_penalty": 1.1
  }'
```
