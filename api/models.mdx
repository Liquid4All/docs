Pass a model's id as `model` in your request. Your organization's models, with their rate limits and prices, are listed on the [Models](https://console.liquid.ai/dashboard/models) page of Liquid Console, and [`GET /openai/v1/models`](/api/reference/models/list-models) returns the ones you can call. See the [Liquid AI pricing page](https://www.liquid.ai/pricing) for current prices.

## Generation models

Call these through [chat completions](/api/guides/text-generation).

| Model | Input | Output | Best for |
| ----- | ----- | ------ | -------- |
| `lfm3-1.7b` | Text | Text | Fast agents, tool use, and everyday chat. |
| `lfm3-vl-2b` | Text, images | Text | [Vision](/api/guides/vision): describing, reading, and reasoning about images. |
| `lfm3-audio-2b` | Text, audio | Text, speech | [Audio](/api/guides/audio): transcription, translation, and spoken replies. |
| `lfm3-omni-2b` | Text, audio, images | Text, speech | [Audio](/api/guides/audio) and images in one conversation. |
| `lfm2.5-24b-a2b` | Text | Text | Our largest model: a reasoning mixture of experts (24B, 2B active) for harder tasks. |

Hosted input limits can differ from a checkpoint's native context length. Check the selected model in [Liquid Console](https://console.liquid.ai/dashboard/models) before sizing requests; the open-weight model card alone does not establish the hosted limit.

## Decision models

Call these through the [decisions endpoint](/api/guides/decisions). They answer typed questions with calibrated probabilities and never generate tokens.

| Model | Input | Context window | Best for |
| ----- | ----- | -------------- | -------- |
| `d1.2-ultra` | Text, images, audio | 65,536 | The most capable decision model, for harder decisions. |
| `d1.2` | Text, images, audio | 65,536 | The default decision model: faster, at less than half the price. |

`d1.1`, `d1-ultra`, and `d1` are deprecated: use `d1.2` or `d1.2-ultra` instead. See [Deprecations](/lfm/help/deprecations#deprecated-api-models).

## Open-weight models

Most of these models are also open-weight, so you can run them yourself on laptops, phones, and GPUs. See [Liquid Foundation Models](/lfm/models/complete-library) for every model and how to run it.
