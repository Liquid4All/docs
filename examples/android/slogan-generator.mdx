This example demonstrates how to use llama.cpp for **single-turn generation** tasks on Android. The SloganApp generates creative product slogans on-device using local language models, showcasing how to integrate AI capabilities for specific product needs without requiring cloud connectivity.

Built with traditional **Android Views**, this example provides a different UI approach compared to Jetpack Compose, making it ideal for teams working with legacy Android codebases.

## What's inside?

The SloganApp showcases:

- **Single-turn Generation** - Generate creative output without maintaining conversation context
- **Traditional Android Views UI** - Implementation using XML layouts and View-based architecture
- **On-device Processing** - Complete privacy with local model inference
- **Simple Integration** - Minimal setup for focused AI tasks
- **Product-focused Prompting** - Optimized prompts for marketing and slogan generation

This example is perfect for understanding how to integrate llama.cpp into existing Android applications that use the traditional View system rather than Jetpack Compose.

<Accordion title="llama.cpp Dependency Setup">
  Add [llama.cpp](https://github.com/ggml-org/llama.cpp) as a git submodule, include its [`examples/llama.android/lib`](https://github.com/ggml-org/llama.cpp/tree/master/examples/llama.android) module in `settings.gradle.kts`, and add it to your app-level `build.gradle.kts`:

  ```kotlin
  dependencies {
      implementation(project(":lib"))

      // Android UI components
      implementation("androidx.appcompat:appcompat:1.6.1")
      implementation("com.google.android.material:material:1.11.0")
      implementation("androidx.constraintlayout:constraintlayout:2.1.4")
  }
  ```

  The lib loads its CPU backends from the app's native library folder, so set `android:extractNativeLibs="true"` on the `<application>` tag in `AndroidManifest.xml`.
</Accordion>

## Understanding the architecture

### Traditional Android Views Approach

Unlike examples that use Jetpack Compose, SloganApp demonstrates integration with the traditional Android View system:

**XML Layout Structure:**
```xml
<!-- activity_main.xml -->
<LinearLayout>
    <EditText
        android:id="@+id/productInput"
        android:hint="Enter product name or description" />

    <Button
        android:id="@+id/generateButton"
        android:text="Generate Slogan" />

    <TextView
        android:id="@+id/sloganOutput"
        android:textStyle="italic" />
</LinearLayout>
```

**Activity Implementation:**
```kotlin
import android.app.DownloadManager
import android.net.Uri
import com.arm.aichat.AiChat
import com.arm.aichat.InferenceEngine
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.MainScope
import kotlinx.coroutines.delay
import kotlinx.coroutines.flow.collect
import kotlinx.coroutines.flow.onEach
import kotlinx.coroutines.launch
import kotlinx.coroutines.withContext
import java.io.File

class MainActivity : AppCompatActivity() {
    private val mainScope = MainScope()
    private var runner: InferenceEngine? = null

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)

        mainScope.launch {
            val model = downloadModel(
                url = "https://huggingface.co/LiquidAI/LFM2.5-1.2B-Instruct-GGUF/resolve/main/LFM2.5-1.2B-Instruct-Q5_K_M.gguf",
                file = File(getExternalFilesDir(null), "LFM2.5-1.2B-Instruct-Q5_K_M.gguf"),
            )
            runner = withContext(Dispatchers.Default) {
                AiChat.getInferenceEngine(applicationContext).also { it.loadModel(model.absolutePath) }
            }
            generateButton.isEnabled = true
        }

        generateButton.setOnClickListener {
            val product = productInput.text.toString()
            generateSlogan(product)
        }
    }

    private fun generateSlogan(product: String) {
        val runner = runner ?: return
        val prompt = """
            Create a compelling, memorable slogan for: $product
            Make it concise, catchy, and professional.
        """.trimIndent()

        sloganOutput.text = ""
        mainScope.launch {
            runner.sendUserPrompt(prompt)
                .onEach { piece ->
                    sloganOutput.append(piece)
                }
                .collect()
        }
    }

    // Downloads the GGUF once with DownloadManager and reuses it on later launches
    private suspend fun downloadModel(url: String, file: File): File {
        if (file.exists()) return file
        val dm = getSystemService(DownloadManager::class.java)
        val id = dm.enqueue(DownloadManager.Request(Uri.parse(url)).setDestinationUri(Uri.fromFile(file)))
        while (true) {
            dm.query(DownloadManager.Query().setFilterById(id)).use { c ->
                if (c.moveToFirst()) when (c.getInt(c.getColumnIndexOrThrow(DownloadManager.COLUMN_STATUS))) {
                    DownloadManager.STATUS_SUCCESSFUL -> return file
                    DownloadManager.STATUS_FAILED -> error("Model download failed")
                }
            }
            delay(500)
        }
    }
}
```

### Single-turn Generation Pattern

This example demonstrates **single-turn generation**, where:
- Each request is sent as a single user prompt; the engine keeps earlier requests in its context until the model is reloaded
- The streamed text pieces are appended to the UI as they arrive
- No need to manage conversation state or context across requests
- Ideal for focused tasks like slogan generation, summarization, or classification

This pattern is simpler than multi-turn conversations and perfect for specific use cases where context isn't needed.

### Model Selection

The app uses **LFM2.5-1.2B-Instruct** (Q5_K_M), a lightweight model that balances:
- **Speed** - Fast generation for responsive UI
- **Quality** - Creative and coherent slogans
- **Size** - ~850 MB on disk; comfortably fits in mobile RAM
- **Efficiency** - Lower memory and battery consumption than larger checkpoints

For higher-quality outputs, swap the download URL to another GGUF from [Liquid AI on Hugging Face](https://huggingface.co/LiquidAI).
