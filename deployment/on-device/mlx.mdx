<Tip>
  Use MLX for running models on Apple Silicon Macs with Metal GPU acceleration.
</Tip>

MLX runs LFMs on Apple Silicon's Metal GPU. Use MLX-VLM for LFM3; MLX-LM remains the text-generation path for supported older models.

## LFM3 and d1 Models

The LFM3 models and the d1 decision models run with [MLX-VLM](https://github.com/Blaizzy/mlx-vlm) 0.8.0:

```bash
uv pip install "mlx-vlm==0.8.0"
```

The LFM3 models run with `mlx_vlm.generate`:

```bash
# LFM3-1.7B: text
python -m mlx_vlm.generate --model LiquidAI/LFM3-1.7B-MLX-4bit \
  --prompt "What is the capital of Australia?" --enable-thinking \
  --temperature 0.1 --top-k 50 --repetition-penalty 1.1 --max-tokens 16384

# LFM3-VL-2B: image
python -m mlx_vlm.generate --model LiquidAI/LFM3-VL-2B-MLX-4bit \
  --image /path/to/image.jpg --prompt "Describe this image." --enable-thinking \
  --temperature 0.1 --top-p 1.0 --top-k 50 --min-p 0.0 --repetition-penalty 1.1 \
  --max-tokens 16384

# LFM3-Audio-2B: speech recognition
python -m mlx_vlm.generate --model LiquidAI/LFM3-Audio-2B-MLX-4bit \
  --system "Perform ASR in English." --prompt "" --audio /path/to/speech.wav \
  --temperature 0 --max-tokens 2048

# LFM3-Omni-2B: text to speech, saved as a 24 kHz WAV file
python -m mlx_vlm.generate --model LiquidAI/LFM3-Omni-2B-MLX-4bit \
  --system "Perform TTS in American English using a female voice." \
  --prompt "The quick brown fox jumps over the lazy dog." \
  --output-modality audio --output tts.wav
```

`mlx_vlm.generate` turns reasoning off unless you pass `--enable-thinking`. mlx-lm cannot load LFM3-1.7B yet. Support is pending in [ml-explore/mlx-lm#2016](https://github.com/ml-explore/mlx-lm/pull/2016).

The d1 models answer questions instead of generating text, and d1-2B and d1-omni-2B refuse `mlx_vlm.generate` and chat apps. Ask them with `python -m mlx_vlm decide`, which prints the answers as JSON:

```bash
python -m mlx_vlm decide --model LiquidAI/d1-2B-MLX-4bit \
  --state "I was charged twice this month. Please refund one of the charges." \
  --questions '{"refund": {"type": "noul", "instructions": "Is the customer asking for a refund?"}}'
```

Swap the model id to ask d1-omni-2B, d1-3B, or d1-omni-600M. d1-3B and d1-omni-600M return yes/no answers as `value` and `probability`. The d1 model cards show the Python API.

## LFM2 and LFM2.5 text models

Use MLX-LM for older text checkpoints, including small, Japanese, and larger MoE models. These examples use MLX-LM 0.32.2. The LFM3 commands above use a different package; changing only the model ID in an MLX-LM command does not add LFM3 support.

```bash
uv pip install "mlx-lm==0.32.2"
python -m mlx_lm.generate --model LiquidAI/LFM2.5-1.2B-Instruct-MLX-4bit \
  --prompt "What is the capital of France?" --max-tokens 512
```

For the Python API, apply the tokenizer's template with `tokenize=False` and pass a sampler:

```python
from mlx_lm import load, generate
from mlx_lm.sample_utils import make_sampler

model, tokenizer = load("LiquidAI/LFM2.5-1.2B-Instruct-MLX-4bit")
prompt = tokenizer.apply_chat_template(
    [{"role": "user", "content": "What is the capital of France?"}],
    tokenize=False,
    add_generation_prompt=True,
)
response = generate(
    model, tokenizer, prompt=prompt, max_tokens=512,
    sampler=make_sampler(temp=0.1, top_k=50),
)
print(response)
```

For an existing LFM2 deployment, keep its own model repository and sampling settings. For older vision checkpoints, use MLX-VLM and the repository linked on the selected [model page](/lfm/models/vision-models).

## Speculative Decoding

For LFM3, the [community DSpark example](/lfm/key-concepts/speculative-decoding#lfm3-speculative-decoding) uses llama.cpp. The MLX-VLM example below is specifically for **LFM2.5-VL-3B** and its official drafter; it does not establish support for the LFM3 drafter. DSpark can accelerate generation by verifying proposed tokens together. Pass the drafter to MLX-VLM (v0.7.2 or newer) with `--draft-model`:

```bash
python -m mlx_vlm.generate \
  --model LiquidAI/LFM2.5-VL-3B \
  --draft-model LiquidAI/LFM2.5-VL-3B-DSpark \
  --draft-block-size 8 \
  --image /path/to/image.jpg \
  --prompt "Describe this image." \
  --max-tokens 256 \
  --temperature 0
```

DSpark in MLX-VLM currently supports greedy sampling only, so keep `--temperature 0`. See [Speculative Decoding](/lfm/key-concepts/speculative-decoding) for which models have drafters.
