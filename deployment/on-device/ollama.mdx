Start with the official [LFM3 model](https://ollama.com/library/lfm3) for local text chat, agents, and tool use. The commands below were checked with Ollama 0.40.16. Install or update Ollama from [ollama.com](https://ollama.com/download), then start its local service.

## Run LFM3

```bash
ollama run lfm3
```

Ollama downloads the model and its template. The official `lfm3` model supports thinking and tools. Leave enough output tokens for reasoning; a short generation cap can stop before the final answer.

## Native chat API

```bash
curl http://localhost:11434/api/chat \
  -H "Content-Type: application/json" \
  -d '{
    "model": "lfm3",
    "messages": [{"role": "user", "content": "What is the capital of France?"}],
    "stream": false,
    "options": {"num_ctx": 4096, "num_predict": 2048, "temperature": 0.1}
  }'
```

The native response separates `message.thinking` from `message.content`. Set `stream: true` to receive newline-delimited JSON chunks. Send the full conversation history for follow-up questions, including tool calls and results when applicable.

## OpenAI-compatible API

Install the client with `uv pip install openai`:

```python
from openai import OpenAI

client = OpenAI(base_url="http://localhost:11434/v1", api_key="ollama")
response = client.chat.completions.create(
    model="lfm3",
    messages=[{"role": "user", "content": "What is the capital of France?"}],
    temperature=0.1,
    max_tokens=2048,
)
print(response.choices[0].message.content)
```

For tool use, pass OpenAI-style `tools` and handle the returned `tool_calls`. For JSON constraints, Ollama's native API accepts a JSON schema in `format`. See the [upstream API](https://docs.ollama.com/api) for supported fields in the native and OpenAI-compatible endpoints; their options are not identical.

## Older models and Hugging Face GGUFs

Keep older checkpoints for a concrete size, specialization, or deployment requirement. Use the repository and sampling settings linked on that model's page:

```bash
ollama run hf.co/LiquidAI/LFM2.5-1.2B-Instruct-GGUF:Q4_K_M
```

The native chat request above works by replacing `model` with this exact Ollama model name. The same chat flow also works with `hf.co/LiquidAI/LFM2-1.2B-GGUF:Q4_K_M`, a deprecated checkpoint retained for existing users. Check [Deprecations](/lfm/help/deprecations) before choosing it for a new application.

Capabilities depend on the imported model's template and Ollama metadata. Successful text generation does not establish tool, vision, audio, or video support. In particular, the original LFM2-1.2B Hugging Face import was checked for chat; it rejects the tool request used with `lfm3`. Do not copy LFM3 tool claims to every older import.

For images, speech, or combined inputs, follow the selected [model page](/lfm/models/complete-library) and its supported runtimes. A GGUF's availability alone does not establish Ollama modality support; [llama.cpp](/deployment/on-device/llama-cpp) has the current LFM3 multimodal examples.

## Manage models

```bash
ollama list
ollama show lfm3
ollama stop lfm3
```
