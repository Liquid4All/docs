Use Transformers for direct Python inference, research, and model development. Start with [LFM3-1.7B](/lfm/models/lfm3-1.7b) for text and agents, or [LFM3-VL-2B](/lfm/models/lfm3-vl-2b) for images and video. For an OpenAI-compatible serving endpoint, see [vLLM](/deployment/gpu-inference/vllm) or [SGLang](/deployment/gpu-inference/sglang).

## Installation

Use a Python 3.12 environment. The examples use Transformers 5.23.0:

```bash
uv pip install "transformers==5.23.0" torch accelerate pillow torchvision
```

GPU inference is recommended. LFM3 checkpoints provide custom configuration, model, and processor code: review the repository before enabling `trust_remote_code=True`. LFM2 and LFM2.5 text/VL models use built-in Transformers classes and do not need it.

[Open the LFM3 notebook in Colab](https://colab.research.google.com/github/Liquid4All/docs/blob/main/notebooks/LFM3_Inference_with_Transformers.ipynb).

## Text generation

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_id = "LiquidAI/LFM3-1.7B"
model = AutoModelForCausalLM.from_pretrained(
    model_id, trust_remote_code=True, device_map="auto", dtype="bfloat16",
)
tokenizer = AutoTokenizer.from_pretrained(model_id, trust_remote_code=True)

inputs = tokenizer.apply_chat_template(
    [{"role": "user", "content": "What is the capital of France?"}],
    add_generation_prompt=True, tokenize=True,
    return_tensors="pt", return_dict=True,
).to(model.device)

output = model.generate(
    **inputs, do_sample=True, temperature=0.1, top_k=50,
    repetition_penalty=1.1, max_new_tokens=2048,
)
print(tokenizer.decode(output[0, inputs["input_ids"].shape[1]:], skip_special_tokens=True))
```

The model reasons before answering, and this raw decode includes that reasoning. A token limit can stop generation before the final answer. See [Thinking](/lfm/key-concepts/thinking) for output controls and [Chat Template](/lfm/key-concepts/chat-template) for response parsing and history handling. Use a larger output budget for tasks that need longer reasoning.

For streaming, pass `TextStreamer(tokenizer, skip_prompt=True, skip_special_tokens=True)` as `streamer` to `model.generate()`. Streaming the raw tokens also streams the reasoning; it does not separate a final-answer channel.

## Vision and video

LFM3-VL uses `AutoModelForImageTextToText` and `AutoProcessor`, both with `trust_remote_code=True`. Its processor formats image/video messages and its checkpoint provides a response parser. Follow the complete [LFM3-VL quickstart](/lfm/models/lfm3-vl-2b#quick-start) and [Vision Capabilities](/lfm/key-concepts/vision-capabilities) examples for image loading, video frame controls, and reasoning-aware output parsing.

## Audio and omni

[LFM3-Audio](/lfm/models/lfm3-audio-2b#quick-start) and [LFM3-Omni](/lfm/models/lfm3-omni-2b#quick-start) use `AutoModelForMultimodalLM` with their own processors. Install the audio/video dependencies on those pages; a text-model script is not sufficient. Use the requested output modality explicitly when you want text rather than speech.

## LFM2.5 and LFM2 compatibility

The text loading, chat-template, and generation flow above also applies to older text models. Change the model ID, omit `trust_remote_code`, and use that checkpoint's sampling settings:

| Model | Temperature | Other sampling settings |
| --- | --- | --- |
| LFM3-1.7B | 0.1 | `top_k=50`, `repetition_penalty=1.1` |
| LFM2.5-1.2B-Instruct | 0.1 | `top_k=50`, `repetition_penalty=1.05` |
| LFM2-1.2B (deprecated) | 0.3 | `min_p=0.15`, `repetition_penalty=1.05` |

Older VL checkpoints use `AutoModelForImageTextToText` and `AutoProcessor` without remote code. They have different image-processing settings and do not use LFM3's response parser. Follow the selected [vision model page](/lfm/models/vision-models).

Keep larger MoEs, Japanese specialists, and smaller models when their task or memory footprint is a better fit. Their model pages specify context limits and generation settings; defaults from one checkpoint are not universal.

The [older Transformers notebook](https://github.com/Liquid4All/docs/blob/main/notebooks/LFM2_Inference_with_Transformers.ipynb) remains scoped to LFM2/LFM2.5. Use the examples above for LFM3.
